# formflow

问卷条件字段求值库：在答案变化时计算字段显隐与有效答案视图。

## 语义

- 只处理字符串答案；未填写（无 key）与空字符串不同。
- 字段没有显隐规则时始终可见；有规则时任意条件组满足即可显示，同组内所有条件都必须满足。
- 条件 = 被引用字段当前可见，且其原始答案等于指定字符串。
- 可见性采用最小不动点语义：必须有从无条件字段出发的有限证明，环不能自行显示，外部支撑撤销后整环隐藏。
- 隐藏不删除：会话保留隐藏字段的原始答案，但有效答案视图不包含它，它也不能支撑其他字段；重新显示后旧答案自动恢复。

## API

- `Compile(def Definition) (*Compiled, error)`：编译定义，可复用于多个会话。
- `Open(c *Compiled, initial map[string]string) *Session`：创建独立会话并计算初始可见性。
- `s.Patch(ops ...Op) Diff`：批量赋值（`Set(field, value)`）或清除（`Clear(field)`），返回可见性或有效答案发生变化的字段及其新状态；与批内处理顺序无关（同一字段一批内只应出现一次）。
- 查询：`s.IsVisible(field)`、`s.Answers()`（有效视图）、`s.RawAnswers()`（含隐藏字段的原始答案）。

## 运行测试

```sh
go test ./...
```

测试包括：循环支撑撤销/恢复、双独立支撑不过度撤回、隐藏答案不支撑他人、空串与未填写区分、自引用/前向引用，以及对含环定义的随机批量修改对照独立参考实现（含批内顺序交换与差量应用校验）。

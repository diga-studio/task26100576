# FormFlow 条件字段求值

供问卷编辑器使用的 Go 库：在答案变化时计算字段显隐与有效答案。

## 语义

- 只处理字符串答案；未填写（答案不存在）与空字符串是不同状态。
- 字段没有显隐规则时始终可见；有规则时，任一条件组满足即可显示，
  同组内所有条件都必须满足（组内 AND、组间 OR）。
- 条件 = 另一字段的答案等于指定字符串，且该字段当前可见。
- 可见性采用最小不动点语义：必须有从无条件字段出发的有限证明。
  环内字段不能仅靠互相满足而自行显示；外部支撑撤销后整环隐藏。
- 隐藏不等于删除：会话保留隐藏字段的原始答案，但有效答案视图不包含它，
  它也不能支撑其他字段；重新显示后原始答案自动恢复。

## API

- `Compile(def Definition) (*Compiled, error)`：编译定义，可并发复用。
- `Open(c *Compiled, initial map[string]string) *Session`：创建独立会话，
  计算初始可见性与有效答案。
- `s.Patch(changes []Change) []FieldDelta`：批量赋值/清除，
  返回可见性或有效答案发生变化的字段；仅原始隐藏答案变化不出现。
- 查询：`s.Visible(name)`、`s.RawAnswers()`、`s.EffectiveAnswers()`。

## 运行测试

```sh
go test ./...
```

测试包含：循环支撑的撤销/恢复与第二独立支撑、空串与未填写的区分、
自引用，以及随机批量修改与测试内独立参考实现（递归良基证明搜索）的对比，
并验证批内顺序无关、差量应用后得到完整最终视图。
